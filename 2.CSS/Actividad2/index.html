Trabajo Práctico 1: Introducción a CSS

1. Introducción a CSS

CSS (Cascading Style Sheets, u "Hojas de Estilo en Cascada") es el lenguaje que usamos para darle estilo y presentación visual a una página HTML. Mientras que el HTML se encarga de la estructura y el contenido, el CSS se encarga de cómo se ve todo eso: colores, tamaños, tipografías, espaciados, ubicación de los elementos, etc. Separar el contenido (HTML) del diseño (CSS) permite mantener el código más ordenado y reutilizar los mismos estilos en varias páginas.

Diferencia entre display: none y visibility: hidden

La diferencia es que display: none hace que el elemento desaparezca por completo y deje de ocupar espacio, como si no existiera en la página (se saca del flujo del documento). En cambio, visibility: hidden hace que el elemento sea invisible, pero sigue ocupando su espacio en el layout, como si fuera un "hueco vacío" donde debería estar.
